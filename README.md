# Research Proposal Workflow Lab

หน้าเว็บ workshop รายวิชา ภศ 462 ระเบียบวิธีวิจัยและสถิติสำหรับเภสัชกร สัปดาห์ที่ 1 (Critical and Responsible Use of AI in Research) คณะเภสัชศาสตร์ มหาวิทยาลัยธรรมศาสตร์

นักศึกษาทำงานเป็นกลุ่ม ร่างบทที่ 1 ของโครงร่างวิจัยด้วย AI ทีละ task (ระบุปัญหา → ระดมหัวข้อ → วางคำค้น → ค้นและสรุปบทคัดย่อ → ร่างโครงบทนำ → บันทึกการใช้ AI) โดยใช้ Prompt แบบ R–T–F และจบด้วยการดาวน์โหลดผลงานกลุ่มเป็นไฟล์ Word ฉบับร่างของ Portfolio 1

- ทั้งหมดอยู่ในไฟล์เดียว `index.html` ไม่มีขั้นตอน build
- ข้อความที่นักศึกษากรอกเก็บไว้ในเบราว์เซอร์ของเครื่องนั้น (localStorage) ไม่ถูกส่งไปที่ใด
- ไฟล์ Word สร้างในเบราว์เซอร์ด้วย JSZip 3.10.1 (โหลดจาก cdnjs)

ผู้จัดทำ: ดร.ภก.วิรุณ เวชศิริ · คณะเภสัชศาสตร์ มหาวิทยาลัยธรรมศาสตร์
